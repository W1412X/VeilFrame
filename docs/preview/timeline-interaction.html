现有问题（对应当前 Timeline.tsx）

  1. 播放头不能拖。 只有 pointerdown 会跳转，播放头线没有把手，也没有拖动逻辑。用户去拖那条线，没有反应。
  2. 没有缩放与滚动。 整段视频压在一屏里，10 分钟视频每秒约 1.6 px，段很难点中，最小宽度只有 0.4%。
  3. 没有时间刻度。 只能看到顶部文字"播放头 12.3s"，无法判断位置在整段中的哪里。
  4. 播放时视图不跟随。 加上缩放后，播放头会离开可视区域。
  5. 悬停没有反馈。 不知道点下去会跳到哪一秒。
  6. 光标不表达功能。 标尺、播放头、段块、空白轨道都是默认箭头，看不出哪里能拖、哪里能点。
  7. 段的操作离开了时间轴。 选中段后只能去检查器或记快捷键。

优化方案

  1. 标尺与播放头把手是唯一的拖动入口。 光标为 ew-resize，按下即擦洗，拖动时显示时间气泡。轨道空白处的按下也会跳转，段块的点击只做选中。
  2. 缩放与滚动显式化。 Ctrl+滚轮以鼠标位置为中心缩放；Shift+滚轮或触控板横向滚动；原生滚动条常驻。
  3. 总览条。 显示整段视频与当前视口。拖动视口本体平移，拖动两端改缩放，点击其他位置跳到那里。
  4. 倍率与可见范围可读。 缩放按钮旁显示"×倍率 · N 秒可见"。
  5. 跟随播放与显式状态。 播放时视口跟随。手动滚动后暂停跟随，并出现"回到播放头"按钮。
  6. 段操作就地化。 选中段后底部信息条显示范围、状态，并提供接受、否决按钮和对应键位。双击段放大到该段。
  7. 悬停参考线与时间。 鼠标移到轨道上显示虚线与时间，用户知道点下去会去哪里。
  8. 键位常驻。 底部一行列出常用快捷键，不再依赖点击"?"后的短暂提示。

其他交互问题（按操作路径分析）

路径 / 位置问题建议
扫描入口 "扫描此目标"在检查器里，"扫描全部"在侧栏，进度条悬浮在窗口底部，取消按钮藏在进度条里。 把进度与取消放进时间轴顶部同一位置，与扫描入口的状态保持一致。
否决 → 负样本 "否决时记为负样本"默认勾选，藏在段面板里。它会全局上调该目标阈值，影响下一次扫描，用户不知道。 在否决按钮旁显示影响说明，例如"下次扫描阈值 0.60 → 0.61"。默认不勾选，或在首次否决时提示一次。
反馈消息 顶部提示 3 秒后消失。扫描范围无效、模型未就位、自动保存失败这类错误也会消失。 错误消息持久显示，直到用户关闭；成功消息保留 3 秒即可。
关键帧拖动 只有选中段后才能拖四角，画面上没有提示"拖动 = 在当前时刻写入关键帧"，拖完也没有撤销提示。 拖动时显示"第 x 秒关键帧"，松手后给出可撤销的提示条。
原画对比 只能用 \ 切换，底部栏没有对应按钮。 提供"按住看原画"（按住 Tab 或按住按钮），松开即恢复打码画面。
导出 "待确认段也打码"默认开，用户可能在未复核时直接导出。 导出前显示"将打码 N 段，其中待确认 M 段"，并在对话框里高亮未复核数量。
批量队列 切换到队列视图后，编辑器的上下文（当前时刻、选中段）丢失。 切换时保留当前项目的时间与选中状态，队列里已复核的任务标注"已复核"。
