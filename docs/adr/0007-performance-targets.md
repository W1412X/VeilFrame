# ADR-0007：性能指标是估算，需要以实测为准

- 状态：Proposed
- 日期：2026-11-20
- 关联：`first_design.md` 2.9（性能预算）、2.11（基准集指标）

## 背景

文档给出了"10 分钟 1080p 视频，标准模式约 2.5–4 分钟"这样的数字，并且注明是量级估算。但文档没有给出测试视频、硬件配置的完整说明，也没有对应的验收方法。如果直接以这些数字作为验收标准，结果无法判定。

## 问题

1. 估算使用的 RTX 3060 与本机 GPU 不一定相同。本机驱动版本为 591.86，但具体型号和显存需要单独确认。
2. "SIFT 3000 帧 8 线程 10–18 秒"依赖特征点数量、模板数量和 ROI 大小，文档没有给出这些前提。
3. 2.11 的基准集（台标、透明水印、滚动字幕等）目前不存在，需要有人采集或制作。

## 建议

1. 第一期只定义**指标种类**，不定死数字：
   - 处理时长 / 视频时长（倍速）
   - 漏检率（人工确认后仍漏的段数 / 真实段数）
   - 误检率（误检段 / 检出段）
   - 段级 IoU
2. 基准集先做 5 段左右的小样本，每段标注真值（起止时间与四角坐标），放在 `bench/` 下，并记录采集条件。
3. 数字在 M2 之后根据实测结果回填到文档，不再保留估算值作为验收线。

## 需要你确认

1. 你是否能提供或允许我使用一批代表性视频做基准集。
2. 你的目标硬件（GPU 型号与显存、CPU 核数）。
3. 可接受的漏检率与误检率上限。
