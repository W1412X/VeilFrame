# ADR-0004：模型与第三方组件的许可证

- 状态：Accepted（2026-11-20）
- 日期：2026-11-20
- 关联：`first_design.md` 2.1（模型表）、2.3（LightGlue / line2Dup）

## 背景

2026-11-20 用户确认两点：本项目不对外分发、不商用；语义对象（人脸、车牌、证件、YOLO 检测器）从范围中删除。因此原先列出的 YOLO（AGPL 风险）和人脸、车牌模型条目不再适用。

剩余的第三方组件仍需在引入时核对许可证。下列结论来自一般了解，**引入前必须逐个核对官方仓库的 LICENSE 与模型卡**。

## 需要核对的组件

| 组件 | 文档用途 | 需要核对的问题 |
|---|---|---|
| PP-OCRv5（det/rec） | 文本感知 | 通常为 Apache-2.0，需确认具体权重的条款 |
| SuperPoint | 精准档特征（M6） | 原始作者的许可证可能限制商用，需确认 |
| LightGlue | 精准档匹配（M6） | 代码通常为 Apache-2.0；使用的 SuperPoint 权重条款需单独确认 |
| PP-OCRv4（PoC 中的 ONNX） | 备选 OCR | 与 PP-OCRv5 的许可证一致的话可以替换使用，需确认来源 |
| line2Dup | 无纹理 logo / 透明水印（形状匹配） | 它不是 OpenCV 核心模块，需确认实现来源与许可证 |
| OpenCV | 视觉基础库 | Apache-2.0，但 contrib 与非自由算法模块需单独确认 |
| ONNX Runtime | 推理引擎 | MIT |

## 我的建议

1. 在仓库中建立 `models/LICENSES.md`，每个模型记录来源、版本、许可证、SHA-256。
2. 不把任何模型权重提交进 git。
3. 模型文件放在仓库外，通过配置文件指定路径。

## 待确认

无。用户确认不对外分发，因此 GPL 构建的 FFmpeg 可用于本地（见 ADR-0002）。
